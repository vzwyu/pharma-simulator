# 药企模拟器 · Pharma Simulator

网页端模拟经营游戏：加入一家虚构药企，从县域市场做起，带团队、抢准入、做学术，
一路升到营销总监。核心张力在于**增长与合规的取舍**——带金销售短期最快，但风险敞口会累积到某一次检查。

## 玩法骨架

- **周回合制**：1 个月 = 4 周，每周有管理精力，周末结算并开周会。
- **周会**：给团队定调（冲量 / 抓学术 / 做客情 / 抓合规），执行度由代表忠诚与标签决定。
- **终端 × 品种矩阵**：一个格子只归一名代表，可在矩阵里直接下拉选人，颜色区分代表。
- **代表标签**：1–2 个可见标签 + 1–3 个隐藏特质；可用「猜标签」反推，猜中加管理加成，猜错扣忠诚。
- **医共体**：同一代表覆盖 ≥2 家成员，准入开发与份额有加成，但管理当量更高。
- **项目**：有失败率与延迟（医院开发 1 个月、病例征集 2 个月）。
- **管理事件**：公司要求分「严格执行 / 选择执行 / 不执行」，不执行会引来专项核查。
- **随机世界**：每局重新生成省市县名、终端、4 个品种（中成药 / 基药 / 生物制剂 / 仿制化药）与竞品名。

## 运行

直接用浏览器打开 `dist/药企模拟器.html`（单文件、零依赖）。

## 开发

```
python build.py        # 把 src/ 内联成 dist/药企模拟器.html
node test/sim5.js      # 无头跑全流程，检查数值曲线
node test/unit.js      # 单元校验（医共体、院边药店、延迟项目、失败率）
```

- `src/js/data.js` — 配置、随机世界生成、标签、项目、事件
- `src/js/engine.js` — 状态与结算
- `src/js/ui.js` — 渲染

## 免责

虚构作品，企业与人物均无对应。游戏中的违规操作都设有对应的监管后果，长期最优解是合规经营。
